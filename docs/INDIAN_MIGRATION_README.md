# Sentinel-AI: Indian Banking & Financial Cybercrime Synthetic Data Migration

This project includes a secondary data generation script specifically designed for Indian Banking and Anti-Money Laundering (AML) scenarios, which enforces the Reserve Bank of India (RBI) rules and uses Indian identifiers.

This dataset transitions the system from global data to an Indian context.

## What is generated?

- **Entities (`threatsightEntities`)**: Indian individuals and businesses with PAN, masked Aadhaar, GSTIN, and Indian addresses (Mumbai, Delhi, Bengaluru, Surat).
- **AML Transactions (`transactionsv2`)**: Includes generic UPI, IMPS, RTGS, and FASTag transactions.
- **Relationships (`threatsightRelationships`)**: Multi-hop connections modeling Beneficial Ownership (UBO), directors, and holding-subsidiary structures compliant with the 10% UBO RBI Rule.
- **Fraud Customers & Transactions (`customers` / `transactions`)**: Contains Indian profiles and transactions, highlighting specific Indian cybercrime typologies.
- **Fraud Patterns (`fraud_patterns`)**: 5 predefined patterns, including:
  1. Rule 114B PAN Structuring (Transfers between ₹48,000 and ₹49,950 to avoid ₹50,000 PAN limit).
  2. PMLA CTR Cash Deposits (Cash deposits exceeding ₹10 Lakhs).
  3. UPI Mule Ring Fan-out (I4C 1930 Cyber Helpline pattern).
  4. Digital Arrest Cyber Scam (Overnight RTGS).
  5. Shell Entity Hawala Layering.

## Key Changes from Default Dataset

To ensure stability in our system (which requires 384-dim embeddings for vector search), **this dataset generates 384-dimensional vector embeddings instead of the raw notebook's 1536-dimensional embeddings**. 

## Data Generated Sources

The synthetic Indian data is entirely generated by the standalone Python script:
- **Source Script**: [`aml-backend/generate_indian_demo_data.py`](aml-backend/generate_indian_demo_data.py)

This script acts as the single source of truth for the Indian data migration. It explicitly partitions the data into two MongoDB databases:

1. **AML Backend Database (`threatsight360`)**:
   - `threatsightEntities`: 105 entities generated.
   - `transactionsv2`: 10,000 AML transactions generated.
   - `threatsightRelationships`: 3 multi-hop graph edges linking shell companies and directors.
   - `fraud_patterns`: 5 384-dimensional vector embeddings for AI vector search.

2. **Fraud Backend Database (`leafy_bank_bian`)**:
   - No data is explicitly written here by default in this script to prevent clashes, but future customer mock profiles can be directed here as per architecture standards.

## Usage

To generate and overwrite the current demo data with the new Indian dataset:

```bash
cd aml-backend
poetry run python generate_indian_demo_data.py
```

*Note: This script will delete the existing documents in the affected collections before generating the new data.*
